Project Motivation

This project was developed as part of the final project for the Web Programming course. The main goal was not only to deliver a functional application but also to explore the complete process of developing a modern web application.

I chose to experiment with different approaches and technologies — such as React and WebSockets — in order to consolidate knowledge and better understand integration challenges, even if this resulted in a less uniform stack.

Despite deployment difficulties, particularly related to package-lock.json, CI/CD configuration, and the express-session library, I consider this project essential for gaining practical experience and understanding how different pieces of the JavaScript ecosystem can work together.
